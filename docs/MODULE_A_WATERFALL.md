# Module A – Waterfall and requirements

## Project requirements
1. The system shall allow staff to register donor details.
2. The system shall display recorded blood inventory by blood group.
3. The system shall record an emergency request.
4. The system shall compare a request with the exact blood-group stock label and show a demo status.
5. The system shall preserve records in a database.

## Waterfall stages
- Requirements: collect and approve the requirements above.
- Design: prepare database entities and page flow.
- Implementation: develop Django models, forms, views and templates.
- Testing: run Django tests and Selenium tests.
- Deployment: run locally or package with Docker.
- Maintenance: correct defects and update requirements.
