# Module B – Scrum after initial release

## Roles
- Product Owner: prioritizes the feature backlog.
- Scrum Master: helps the team follow Scrum.
- Developers: implement and test features.

## Example backlog
1. As staff, I want to register a donor.
2. As staff, I want to view inventory.
3. As staff, I want to record an emergency request.
4. As staff, I want to see recent requests.

## Sprint example
- Sprint planning: select donor registration and inventory.
- Daily Scrum: share completed work and blockers.
- Sprint review: demonstrate working pages.
- Retrospective: identify what can be improved.
